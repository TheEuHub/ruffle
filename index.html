            Adding or removing a game takes 30 seconds
          
          

            
    
              
  1. Drop your .swf into assets/games/<id>/game.swf.
    2. 
              
  2. Add one block to games.json (or run node scripts/add-game.mjs mygame.swf "My Game").
    3. 
            

            
To remove a game, delete its block from games.json (and its folder). Nothing else to touch.

            
Then run npm run build-offline to refresh the single-file copy — or just grab it with the
              Offline button above; double-clicking it works with no server and no internet.
